```bash

```

**API Errors:**
```bash

```

**Gateway Issues:**
```bash
systemctl status openclaw-gateway                # Check status
journalctl -u openclaw-gateway -n 100            # Review logs
sudo systemctl restart openclaw-gateway          # Restart
```

**Session Corruption:**
```bash
find ~/.openclaw/sessions -name "*.jsonl" -size 0     # Find issues
cp -r ~/.openclaw/sessions ~/.openclaw/sessions.backup  # Backup
find ~/.openclaw/sessions -name "*.jsonl" -size 0 -delete  # Clean
```
